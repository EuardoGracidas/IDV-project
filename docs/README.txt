Mapping the Spotify Soundscape — local website
=================================================
Open index.html in any modern browser (double-click it). You don't need a server
or an internet connection.

  index.html     story + figures
  css/style.css  theme (same "late-night vinyl" palette as the notebook)
  js/data.js     genre percentile profiles used by the interactive radar
  js/main.js     scroll progress, reveal animations, lightbox, interactive radar
  img/           the 15 figures exported from spotify_soundscape.ipynb (JPG, 2000 px)

To update figures: rerun the notebook, then re-export figures/*.png into img/ as .jpg.
